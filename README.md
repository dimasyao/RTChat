# RTChat

RTChat is a simple real-time chat application. The backend is built using .NET 8, while the frontend is developed with React. SignalR enables real-time communication, and Azure Cognitive Services Text Analytics API is used to analyze the sentiment of chat messages.
Real-Time Communication: Powered by SignalR, RTChat enables instant message delivery and a smooth chatting experience.
Sentiment Analysis: Integrated with Azure Cognitive Services Text Analytics API, the application analyzes the sentiment of each message, giving users insights into the tone of the conversation.
Scalable Architecture: Designed with scalability in mind to support real-time interactions for a growing user base.

⚙️ Deployment
RTChat is ready for deployment on cloud platforms. It has been successfully tested with Azure Container Instances, leveraging Docker images for both the frontend and backend.
